离店学情日报

学生离店后，伴学师在手机端核对学情（含相对周均变化）、补写线下观察，一键生成可发企微的家长消息；支持改稿、复制、发送，并连续处理下一位。家长回复经企微回调进入「待回复」。改稿原因与语气切换沉淀为训练信号。

问题一

伴学师日常哪些环节优先用 AI 优化

拾光伴学的交付链路是：伴学本负责学、空间负责场、伴学师负责管。伴学师人效瓶颈不在「有没有数据」，而在「看完数据后如何当晚形成可发给家长的判断与话术」。现有智能运营系统已具备时长、任务完成、知识点掌握度、到店/离店与专注等字段；缺口在决策与生成层。

候选能力用商业价值 × 落地可行性排序。商业价值看：家长当日是否感知服务、是否服务续费沟通、写法能否复制到加盟店。落地可行性看：主数据是否已在伴学本、产出物是否明确、班次内是否可在数分钟内完成、人机责任是否可审计。

综上：第一期把 AI 用在「学情解读 + 家长消息起草」。现场陪伴与情绪安抚仍由伴学师完成；讲题与学科辅导不进入本产品范围。

问题二

第一期核心场景：手机端离店学情日报

用户。门店伴学师（第一用户）；家长为消息接收方；店长可查看超时未回复项，只看不代发。

场景定义。学生离店且当日学情同步完成后，伴学师在手机端打开待办，核对学情指标与相对周均变化，填写线下观察，生成家长消息；在消息区内选择语气（陈述 / 表扬 / 严肃）、编辑、复制或发送；处理完成后进入下一位待处理学生，页面回到顶部。家长在企微回复后，回调进入「待回复」，由伴学师在产品内接手；满 24 小时未处理则升级店长。

端到端链路（按发生顺序）。

  1. 数据接入。 同步字段：到店/离店时间、学习时长、学习内容（学科 + 预习/复习/习题等）、完成进度、错题与薄弱点、专注表现；并计算各指标相对近 7 日周均的升/降/持平。入学未满 7 日的学生不展示周均对比。缺字段时事实区固定显示「数据缺失」，生成时跳过该项、不编造。触发：学生离店或当日数据同步完成 → 进入「待发送」。跨天未处理的待办保留，卡片标「已积压 N 天」，日报数据仍取离店当日，不改成次日口径。
  2. 待办分发。 列表分「待发送 / 待回复 / 已处理」。待发送卡片展示离店时间、时长、完成与周均对比摘要、积压天数。待回复卡片展示家长回句摘要与已等待时长。
  3. 核对学情 + 写观察。 学情区只读，生成前即可核对；每项指标右侧展示相对周均变化（反向指标如错题用语义表达，不单靠箭头颜色）。伴学师必填一句线下观察（到店才可知的信息）。快捷标签作为提示卡，点选插入光标处，不在句尾自动拼接。系统可基于周均变化给出「今晚怎么说」提示，并推荐语气。
  4. 生成家长消息。 观察提交后点击生成。输出为可直接发企微的纯文本：称呼与问候、今日完成（含具体数字）、专注与状态、薄弱点与可操作建议、观察自然融入、落款。数字仅允许来自已同步字段。生成只改消息区，不刷新事实区。
  5. 改稿 / 复制 / 发送。 语气、正文编辑、复制、发送均在「发给家长的消息」模块内完成。改写字符占比低于 20% 时，修改原因默认「措辞调整」，一键确认即可；达到 20% 及以上须选具体原因再确认。原因枚举：措辞调整、AI 识别错误、观察补充、语气不符、其他。语气切换若稿面已有未保存编辑，须确认「保留当前修改」或「用新语气重写」，禁止静默覆盖。发送时做三道程序化校验，任一不通过则拦截标红、不发出：正文数字与事实区逐一比对；家长称谓与学生档案匹配；线下观察句仍在正文中。
  6. 连续处理。 右下角「下一个待处理」进入下一名待发送或待回复学生，并滚至该页顶部。待发送全部发完后进入「已处理」；家长回复后从「已处理」转出到「待回复」。
  7. 家长回复回流。 V1 在产品内承接家长回复：企微回调写入「待回复」待办，算伴学师的班次待办。满 24 小时未响应，升级店长视图（只看不代发，不改发送人）。自动回复不在本期范围。

人机边界。AI：排序提示、周均对比展示、消息起草、语气模板。人：线下观察、改稿、确认反馈、发送决策、回复家长。系统：记录发送人、时间、修改原因、语气切换、发送校验拦截，供审计与迭代。

问题三

产品方案与关键流程（对齐原型）

定位。门店伴学师手机端「离店学情日报」工具。目标是把「数据 → 观察 → 生成 → 发送 → 下一位 → 家长回复回流」在一个班次内走通。

信息架构。待办页含「待发送 / 待回复 / 已处理」三个 Tab，卡片进入学生详情。学生页自上而下为：今日学情（含周均对比，生成前可见）→ 线下观察（必填，标签插入光标处）→ 生成日报 → 发给家长的消息（语气 + 正文 + 复制/发送 + 分级修改原因）→ 底部「下一个待处理」。待回复页展示已发原文、家长回句与跟进输入。

规则（上线门槛）。观察未填不可生成；生成消息不得出现输入外数字与科目；缺字段事实区显示「数据缺失」、生成跳过；入学未满 7 日不展示周均对比；轻微改稿默认「措辞调整」一键确认，大改须选原因；语气切换不得静默覆盖已改正文；发送前三道校验不通过不得发出；「下一个待处理」进入下一位并回到页面顶部；家长回复进「待回复」，24 小时未处理升级店长（只看不代发）。

生成约束（对接模型提示词）。角色为伴学师本人口吻；结构固定为称呼、今日完成、专注与状态、薄弱点与建议、观察融入、落款；全文建议不超过 300 字；禁止空泛夸奖、成绩承诺、焦虑措辞、续费促销、「根据数据显示」等机器口吻，以及伴学师内心独白和对家长的指令句（如「请保证明天按时到店」）。

打开先看今晚要写的人。待发送里陈思远已积压 1 天；家长回了进待回复。点进去核对学情后写观察再生成。

问题四

研发关注点、评测流程与指标目标

北极星。当日日报完成率 = 当日离店学生中，日报已触达家长的比例。链路、使用、质量指标支撑北极星；投诉与「话术制造焦虑」是护栏，不替代完成率。

1. 研发重点。

数据。主链路对接伴学本与门店到离店记录。必选字段：学生、科目、时长、到店/离店、学习内容类型、完成进度、错题（题量+知识点）、专注；并产出周均基线用于对比。缺字段时事实区固定显示「数据缺失」，不隐藏该项，模型不得补数。入学未满 7 日：该指标不展示周均对比（界面为「—」）。跨天积压：待办保留并标「已积压 N 天」，事实仍取离店当日。

生成。观察提交后触发生成；超时需可重试。事实句只引用已同步字段；语气模板（陈述/表扬/严肃）与推荐逻辑可配置。输出落库保存原稿与终稿，便于 diff。语气切换记独立事件（推荐语气、切换后语气、是否保留编辑），作为推荐采纳率的分子分母。

交互。手机优先。消息模块内完成语气切换、编辑、复制、发送。改稿按改写占比分级：< 20% 默认「措辞调整」一键确认；≥ 20% 须选具体原因。语气切换前若稿面有未保存编辑，弹确认，禁止静默覆盖。发送时执行三道程序化校验，失败拦截并标红。底部仅保留「下一个待处理」，进入下一位时滚动到页顶。

触达与权限。优先企微单发；发送失败可重试且草稿保留。家长回复经企微回调进入「待回复」。加盟店数据按门店隔离；发送记录可审计。内容边界：过程服务口径，不进入讲题与心理诊断标签。已读率依赖企微已读回执；若拿不到回执，已读率降级为送达率，家长侧效果改看回复率。

迭代。修改原因、语气切换与前后文按周汇总，用于提示词与门店模板优化；模板默认按门店隔离。

2. 评测流程。

  1. 离线评测（发版前）。 抽样真实脱敏学情 + 观察，跑生成。人工按清单打分：事实忠实度、观察未篡改、语气合规、结构完整、字数与可读性。不通过则阻断上线。
  2. 门店试点（2–4 周）。 选取 3–5 家店、固定伴学师样本。先开「生成+复制」，再开「一键发送」。每日看链路与使用指标，每周复盘修改原因分布、语气推荐采纳率与典型改稿案例。
  3. 对照评估。 同店试点前后对比：单份沟通耗时、待发送当日完成率、家长送达/回复、异常当天联系达成率。有条件时设对照班次（不用助手 vs 用助手）。
  4. 放量门槛。 同时满足：生成与发送成功率达标、待发送当日完成率达标、事实被改比例可控、家长侧无显著投诉抬升。通过后按加盟区域分批放开。
  5. 持续运营。 周报：修改原因 Top、事实改写案例、超时未发积压率、待回复超时项。月报：续费与投诉等滞后指标，决定是否启动 P1（计划建议强化 / 家长自动回复）。

3. 指标与目标。

层级 指标 目标 警戒线
北极星 当日日报完成率（当日离店学生中日报已触达家长的比例） 班次结束前清完当日待发送；完成率按门店周报盯 连续 3 天完成率下滑，或大量积压到次日
链路 离店后待办出现时效；生成成功率；企微发送成功率 待办 1 分钟内可见；生成成功 ≥ 95%；发送成功 ≥ 99% 生成成功连续 3 天低于 90%
使用 待发送打开率；待发送当日完成率；单份「打开→发送」时长；下一位点击率；语气推荐采纳率 当日完成率按班次清完计；单份 ≤ 5 分钟 单份仍 ≥ 15 分钟，或积压率抬升

5. 风险与未决问题。

  1. 企微已读回执是否可得。 已读率直接依赖企微回执能力，目前不能当作已兑现能力。拿不到回执时：已读率降级为送达率，北极星仍用当日日报完成率（发送成功即触达），家长侧效果改看回复率。在合同与技术联调结论出来前，方案与看板都按「可降级」标注，避免按一个产品里不存在的行为考核。
  2. 未成年人数据合规。 学情数据用于生成家长消息，须落在已签署的服务与隐私授权范围内。生成链路只使用当次日报必要字段；门店隔离；日志脱敏；原稿/终稿留存周期与家长会话存档对齐，到期删除或不可逆脱敏。加盟店不得导出跨店学生明细。
  3. 一线对「观察必填」的阻力。 观察必填是为了保住伴学师的现场价值，避免日报变成数据播报。老手会觉得这是多一次打卡。上线话术需要说清：没观察的稿不能发，不是考核填写率（必填项的填写率接近 100%，该指标已从方案中删除），而是避免「没进过房间也能写完」。店长周会用改稿案例，而不是用填写率排名。
  4. 试点样本偏差。 3–5 家店、固定伴学师，前后对比很难谈统计显著。试点结论只用于放量门槛的方向判断（耗时是否下降、事实改写是否可控、投诉是否抬升），不写成「提升了 X%」对外口径。若试点店偏头部、老手比例高，放量时按加盟区域重新看新人班次。

本期交付边界。P0 交付离店日报手机闭环：待办（含积压）、学情周均对比、观察、生成、分级改稿反馈、语气切换确认、发送前校验、复制/发送、下一个待处理、家长回复回流待办。P1/P2 能力（自动改计划、自动回复家长、硬件专注识别、看板增强）不纳入本版本范围。
